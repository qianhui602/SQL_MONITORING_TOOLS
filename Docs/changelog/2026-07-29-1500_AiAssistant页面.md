# 变更记录 - 新增 AI 助手页面

- **日期**: 2026-07-29 15:00
- **类型**: 新增功能
- **影响范围**: `frontend/src/views/AiAssistant.vue`

## 变更内容
新增 AI 助手（AiAssistant）页面组件，包含完整的 Vue 3 SFC（`<template>`、`<script setup>`、`<style scoped>`）。页面提供：
- 左侧任务历史侧边栏：新建任务按钮、任务卡片列表（显示查询文本、时间、状态圆点）、悬停删除按钮、空状态提示
- 右侧主区域：无任务时的欢迎页（图标 + 标题 + 输入框），有任务时的执行步骤展示（待执行/运行中/完成/失败状态，可展开查看结果或错误），底部输入框
- 3 秒轮询自动刷新任务状态，完成后自动停止
- 简易 Markdown 渲染（加粗、换行、HTML 转义）
- 完整的 i18n 国际化支持
- 暗色主题适配（使用 CSS 变量）
- 自定义滚动条样式

## 变更原因
项目需要一个 AI 助手交互页面，让用户可以通过自然语言描述任务，由 AI 自动规划并执行。该页面已路由注册（`/ai-assistant`），API 接口已就绪（`createAiTask`、`getAiTasks`、`getAiTaskDetail`、`deleteAiTask`），i18n 翻译条目已存在，但缺少前端视图组件。
