# 变更记录 - 新增 AI 任务服务

- **日期**: 2026-07-29 15:47
- **类型**: 新增功能
- **影响范围**: backend/app/models/, backend/app/services/

## 变更内容
新增 AI 诊断任务的后端服务，包括：
1. AI 上下文构建服务（ai_context.py）：自动查询最新监控数据，构建系统上下文供 AI 规划使用
2. 任务规划与步骤执行函数（扩展 deepseek.py）：plan_task 生成诊断步骤计划，execute_step 执行单个步骤
3. 任务执行引擎（ai_executor.py）：协调任务创建、上下文构建、AI 规划和逐步执行
4. AI 任务数据模型（ai_task.py）：AiTask 和 AiTaskStep 两张表，存储任务和步骤状态

## 变更原因
为 SQL 监控工具提供 AI 驱动的诊断能力，支持用户输入诊断需求后自动规划并执行多步诊断任务。
