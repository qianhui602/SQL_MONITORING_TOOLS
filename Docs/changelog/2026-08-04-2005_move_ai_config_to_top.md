# 变更记录 - AI 模型配置上移到系统设置顶部

- **日期**: 2026-08-04 20:05
- **类型**: UI 优化
- **影响范围**: 前端系统设置页面

## 问题描述

`/settings` 系统设置页面中"AI 模型配置"区域位于页面最底部（SQL Server 连接配置 → SMTP 邮件通知 → AI 模型配置），管理员需要向下滚动才能配置 DeepSeek 等 AI 服务。超级管理员反馈"找不到 AI 模型配置入口"。

## 变更内容

将 "AI 模型配置" 区块从原位置（页面底部，SMTP 邮件通知之后）移动到页面顶部，紧随 "品牌设置" 之后，成为第二个配置区块。

新的页面顺序：
1. 品牌设置
2. **AI 模型配置** ← 新位置
3. 系统设置
4. SQL Server 连接配置
5. SMTP 邮件通知
6. （通知测试按钮）

## 变更原因

AI 模型配置是 AI 助手功能的关键前置配置，把它放在页面顶部，管理员打开系统设置后第一眼就能看到，无需滚动。

## 涉及文件

| 文件路径 | 操作（新增/修改/删除） | 说明 |
|---------|---------------------|------|
| `frontend/src/views/Settings.vue` | 修改 | 将 AI 模型配置区块从底部移到顶部 |

## 验证

- 访问 `/settings` 页面，确认 AI 模型配置区块在第二个位置（紧随品牌设置之后）
- 配置 DeepSeek API Key、选择模型，点"保存并应用"
- 进入 AI 助手页面发起任务，确认使用了新配置
