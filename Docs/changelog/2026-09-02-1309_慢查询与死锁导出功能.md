# 变更记录 - 慢查询与死锁导出功能

- **日期**: 2026-09-02 13:09

- **类型**: 新增功能

- **影响范围**: 后端导出接口、前端 API 层、下载工具、i18n 文案、慢查询分析页面、死锁监控页面

## 变更内容

为「慢查询分析」与「死锁监控」两个页面新增 CSV 导出能力，并同步修复既有后端导出接口的缺陷：

### 后端（backend/app/routers/export.py）

1. 修复 `_stream_csv` 的 CSV 转义缺陷：原实现手动拼接 `",".join(f'"{v}"')`，SQL 文本中包含的逗号/引号/换行会破坏 CSV 结构，改为使用标准库 `csv.writer` 逐行写入，正确转义特殊字符。
2. 重写 `export_deadlocks` 接口：

   - 新增筛选参数：`server_address`（实例精确匹配）、`login_name` / `host_name` / `client_app`（模糊匹配），与死锁监控页面筛选条件对齐；

   - 导出列调整为 `发生时间、受害会话ID、SQL Server地址、用户、主机（设备）、应用程序`，与页面表格列一致（原导出缺失用户/主机/应用程序列）。
3. 重写 `export_slow_queries` 接口：

   - 数据库查询移出流式生成器，异常时返回 HTTP 500 而非输出损坏的 CSV 文件；

   - 新增 `server_address` 实例筛选参数及 `sort_by` / `sort_order` 排序参数（支持执行次数/总CPU时间/总逻辑读/平均耗时/最后执行时间/采集时间），与页面排序能力对齐；

   - 导出列调整为 `查询文本、执行次数、总CPU时间(ms)、总逻辑读、平均耗时(ms)、最后执行时间、采集时间、实例地址`，与页面表格列一致。
4. 保留原有机制：UTF-8 BOM 头（Excel 兼容）、StreamingResponse 流式输出、50000 条导出上限。

### 前端

1. `api/index.js`：`exportDeadlocks` / `exportSlowQueries` 增加 120 秒超时（覆盖大数据量导出场景，避免默认 30 秒超时中断）。
2. 新增 `utils/export.js` 工具：

   - `buildExportFilename(prefix, ext)`：生成 `前缀_YYYYMMDD_HHMMSS.csv` 格式文件名；

   - `downloadBlob(blob, filename)`：通过 `URL.createObjectURL` + 动态 `<a>` 标签触发浏览器下载并释放资源。
3. `i18n/zh-CN.js` / `i18n/en-US.js`：common 下新增 `export`（导出/Export）、`exporting`（导出中.../Exporting...）、`exportFailed`（导出失败提示）文案。
4. `SlowQueries.vue`：工具栏新增「导出」按钮，导出时自动携带当前实例筛选、时间范围（最近1小时/6小时/24小时/7天）与排序条件，导出中按钮禁用并显示"导出中..."，失败时提示错误。
5. `Deadlocks.vue`：工具栏新增「导出」按钮，导出时自动携带当前全部筛选条件（实例、开始/结束时间、用户、主机、应用程序），导出中按钮禁用，失败时提示错误。

## 变更原因

- 用户需求：慢查询分析与死锁监控页面的数据需要支持导出（按当前筛选条件）。

- 后端虽已有 `/api/export/*` 接口且前端 API 层已封装，但页面无导出入口，功能链路未打通。

- 顺带修复既有导出接口缺陷：CSV 特殊字符未转义、死锁导出列与页面 UI 不一致且不支持筛选、慢查询导出错误处理缺陷（生成器内查询出错会返回损坏文件）。
