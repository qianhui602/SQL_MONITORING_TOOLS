- **Type**: New feature

## Changes
Added the AI Assistant (AiAssistant) page component, a complete Vue 3 SFC (`<template>`, `<script setup>`, `<style scoped>`). The page provides:
- Left task history sidebar: new task button, task card list (showing query text, time, status dot), hover delete button, empty state hint
- Right main area: welcome page when there is no task (icon + title + input box); execution step display when there is a task (pending/running/completed/failed statuses, expandable to view results or errors), bottom input box
- 3-second polling to auto-refresh task status, stops automatically when complete
- Simple Markdown rendering (bold, line breaks, HTML escaping)
- Complete i18n internationalization support
- Dark theme adaptation (CSS variables)
- Custom scrollbar styles

## Reason
The project needs an AI assistant interaction page that lets users describe tasks in natural language for the AI to plan and execute automatically. The route (`/ai-assistant`) is registered, API endpoints are ready (`createAiTask`, `getAiTasks`, `getAiTaskDetail`, `deleteAiTask`), and i18n entries exist, but the frontend view component was missing.
