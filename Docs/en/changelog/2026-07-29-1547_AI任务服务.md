# Change Log - New AI Task Service

[简体中文](../../changelog/2026-07-29-1547_AI任务服务.md) | **English**

- **Date**: 2026-07-29 15:47
- **Type**: New feature
- **Scope**: backend/app/models/, backend/app/services/

## Changes
Added backend services for AI diagnostic tasks:
1. AI context building service (ai_context.py): automatically queries the latest monitoring data and builds system context for AI planning
2. Task planning and step execution functions (extension of deepseek.py): `plan_task` generates a diagnostic step plan, `execute_step` executes a single step
3. Task execution engine (ai_executor.py): coordinates task creation, context building, AI planning, and step-by-step execution
4. AI task data models (ai_task.py): AiTask and AiTaskStep tables storing task and step status

## Reason
Provide AI-driven diagnostic capability for the SQL monitoring tool, allowing users to input diagnostic requirements and have the AI automatically plan and execute multi-step diagnostic tasks.
