# 变更记录 - 慢查询增加最近3天选项与导出加固

- **日期**: 2026-09-02 14:33
- **类型**: 新增功能 / Bug修复
- **影响范围**: `frontend/src/views/SlowQueries.vue`、`frontend/src/i18n/zh-CN.js`、`frontend/src/i18n/en-US.js`、`backend/app/routers/export.py`

## 变更内容
1. **慢查询分析新增「最近3天」时间范围选项**：
   - `SlowQueries.vue` 的 `timeRangeOptions` 在「最近24小时」与「最近7天」之间加入 `'3d'`；
   - `getTimeRange()` 的 `rangeMap` 增加 `'3d': 72`（72 小时）；
   - `zh-CN.js` / `en-US.js` 的 `slowQueries.ranges` 增加 `'3d'` 文案（最近3天 / Last 3 days）。
2. **慢查询导出加固**（针对 7 天/大数据量导出失败）：
   - `export_slow_queries` 从 `stream_results=True` 改为 `stmt.yield_per(1000)`，每批最多读取 1000 行，避免一次性缓冲最多 50000 行的超大 SQL 文本，服务端游标分批滚动，降低内存并提升大数据导出稳定性；
   - 前端 `SlowQueries.vue` 的 `onExport` 增强失败提示：导出失败时解析后端返回的 `detail` 并展示具体原因（如「查询慢查询记录失败: ...」），便于定位问题。

## 变更原因
用户反馈两点：慢查询分析导出提示「导出失败」；希望增加「最近3天」时间范围选项。
