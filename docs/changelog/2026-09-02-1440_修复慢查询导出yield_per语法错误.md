# 变更记录 - 修复慢查询导出 yield_per 语法错误

- **日期**: 2026-09-02 14:40
- **类型**: Bug修复
- **影响范围**: `backend/app/routers/export.py`

## 变更内容
上一轮将慢查询导出由 `stream_results=True` 改为 `stmt.yield_per(1000)`，导致导出报错：
`查询慢查询记录失败: 'Select' object has no attribute 'yield_per'`。

根因：在 SQLAlchemy 2.0 中，`yield_per()` 是旧版 ORM `Query` 的方法，`select()` 对象（`Select`）没有该方法。

修复：改为 `stmt.execution_options(yield_per=1000)`，该方式在 `select()` 对象上合法，既能启用服务端游标分批读取（每批 1000 行），又避免调用不存在的方法。

已用本地 SQLAlchemy 2.0.52 + `db.stream` 真实执行验证通过（YIELD_PER_OK）。

## 变更原因
`Select` 类型不存在 `yield_per` 属性，导致慢查询导出接口 500 失败。
